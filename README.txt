台股智慧買賣提醒 V2
====================

這是一個可安裝到 Android 主畫面的 PWA 原型。

功能：
- 22 檔觀察池
- 你的持股與成本
- 買進／賣出／換股警報
- 以 TWSE OpenAPI 更新上市股票行情
- 本機儲存持股資料
- 通知權限入口
- 可在手機瀏覽器「加入主畫面」

注意：
1. V2 使用臺灣證券交易所公開 API；行情連線失敗時會保留上次價格。
2. V2 的估值區間目前是研究模型中的靜態安全邊際，不是即時券商估值。
3. 尚未接券商下單，不會自動交易。
4. Android 背景通知受瀏覽器限制；若要做到真正的每日背景推播，下一步應做原生 Android + 後端排程/推播。
5. 不應把模型訊號視為保證獲利或投資建議。




V3.1：取消模擬投資；新增持股手動修正、刪除、新增；App 啟動時自動同步更新最新股價。
